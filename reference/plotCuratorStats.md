# Plot curation output for each curator

Plot curation output for each curator

## Usage

``` r
plotCuratorStats(dat, npc)
```

## Arguments

- dat:

  a `data.frame` storing BugSigDB data.

- npc:

  character. A column of `dat` that contain the curation date in dmy
  format.

## Value

None. Plots to a graphics device.
